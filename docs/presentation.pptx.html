The Challenge

Why We Need Automation

Manual Testing Pain

Testing registration, search, cart, checkout, and payment across 3 browsers takes hours every release.

Business Risk

Critical customer journeys break silently. Bugs reach production because manual testing can't cover everything.

Scale Problem

As features grow, manual effort grows linearly. Automated tests run in minutes regardless of suite size.

Goal: Build a scalable, maintainable Playwright framework that automates all critical e-commerce flows, runs across browsers, and produces clear reports for stakeholders.
Technology Choice

Why Playwright?

Auto-Waiting

No explicit waits. Playwright waits for elements to be visible, enabled, and stable before acting.

// Selenium: you write waits manually
WebDriverWait(driver, 10).until(...)

// Playwright: auto-waits for you
await page.locator('#submit').click();

Built-In Power Tools

  • Network Mocking Intercept and mock HTTP requests natively
  • Trace Viewer Timeline replay of every test action
  • Visual Regression Screenshot comparison built in
  • 3 Browsers Chrome, Firefox, Safari from one API

Architecture Overview

    contact-us.page.ts Contact form
  tests/           Test scenarios
  testdata/        JSON test data
  utils/           Logger, data reader
  reports/         HTML reports, traces

Design Principles

  • Page Object Model — One class per page. Locators defined once.
  • Custom Fixtures — Dependency injection + ad blocking in one place.
  • Data Separation — Test logic separate from test data.
  • Type Safety — TypeScript catches errors at compile time.
When a UI element changes, I update one file — not twenty tests.
Core Pattern

Page Object Model in Action

LoginPage (pages/login.page.ts)

export class LoginPage extends BasePage {
  private readonly signupName: Locator;
  private readonly signupEmail: Locator;
  private readonly signupButton: Locator;

  constructor(page: Page) {
    super(page);
    this.signupName =
      page.locator('[data-qa="signup-name"]');
    this.signupEmail =
      page.locator('[data-qa="signup-email"]');
    this.signupButton =
      page.locator('[data-qa="signup-button"]');
  }

  async startSignup(name: string, email: string) {
    await this.signupName.fill(name);
    await this.signupEmail.fill(email);
    await this.signupButton.click();
  }
}

How the Test Uses It

// user-registration.spec.ts
test('Register a new user', async ({
  homePage, loginPage, signupPage,
}) => {
  const uniqueName =
    `hariteja_${timeStamp}_${rand}`;
  const uniqueEmail =
    `haritejac_${timeStamp}_${rand}@hotmail.com`;

  await homePage.open();
  await homePage.goToLogin();
  await loginPage.startSignup(
    uniqueName, uniqueEmail
  );
  await signupPage.fillRegistrationForm({...});
  await signupPage.submitRegistration();
  await signupPage.verifyAccountCreated();
});

Tests read like business requirements, not HTML details. Every run generates a unique name and email.

Infrastructure

Custom Fixtures & Stability

Dependency Injection

// fixtures/test-fixtures.ts
export const test = base.extend({
  // Block ads that overlay elements
  page: async ({ page }, use) => {
    await page.route(
      /google|facebook|doubleclick
       |googlesyndication|adservice/,
      (route) => route.abort()
    );
    await use(page);
  },

  homePage: async ({ page }, use) => {
    await use(new HomePage(page));
  },
  loginPage: async ({ page }, use) => {
    await use(new LoginPage(page));
  },
  // ... all page objects injected
});

Why This Matters

  • Ad Blocking: automationexercise.com loads Google Ads that overlay clickable elements. Blocking at network level is more reliable than closing popups.
  • Lazy Loading: Page objects are only created when a test requests them.
  • Test Isolation: Each test gets its own browser context. No shared state.

Cart Cleanup Pattern

// Clear leftover items from server-side cart
const deleteButtons =
  page.locator('td.cart_delete a');
let count = await deleteButtons.count();
while (count > 0) {
  await deleteButtons.first().click();
  count--;
}
