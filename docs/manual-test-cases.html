TC-001: User Registration

Test Case IDTC-001
Test Case NameUser Registration with Unique Credentials
ModuleAuthentication
PriorityHigh
Pre-conditionsBrowser is open. User is not logged in. A unique name and email are prepared.
Test DataName: hariteja_[timestamp], Email: haritejac_[timestamp]@hotmail.com, Password: Rules@123, DOB: 19/05/2010
#Test StepExpected ResultStatus
1Navigate to https://automationexercise.com/Home page is displayed with the slider visible.
2Click on "Signup / Login" link in the header.Login page opens showing "New User Signup!" and "Login to your account" sections.
3Under "New User Signup!", enter Name and Email address.Name and Email fields accept input.
4Click the "Signup" button.Registration form page opens with "Enter Account Information" heading.
5Select Title as "Mr".Mr radio button is selected.
6Enter Password as "Rules@123".Password field accepts input.
7Select Date of Birth: Day=19, Month=May, Year=2010.All three dropdowns show selected values.
8Fill in Address Information: First name, Last name, Company, Address, Address2, Country, State, City, Zipcode, Mobile number.All fields accept input correctly.
9Click "Create Account" button."ACCOUNT CREATED!" message is displayed.
10Click "Continue" button.Home page is displayed with "Logged in as [username]" in the header.
11Verify the created credentials are saved to reports/created-accounts.json.JSON file contains the new account with name, email, password, and timestamp.

TC-004: Search and Add Products to Cart

Test Case IDTC-004
Test Case NameBrowse Polo T-Shirts and Add Three to Cart
ModuleProduct Search & Cart
PriorityHigh
Pre-conditionsUser is logged in. Cart is empty (cleared of any previous items).
Test DataCategory: Men > T-Shirts, Brand: Polo, Items to add: First 3 products displayed.
#Test StepExpected ResultStatus
1Log in using the latest created account."Logged in as [username]" is displayed.
2Navigate to Cart and clear any existing items by clicking the X (delete) button on each item.Cart is empty.
3Go to the Home page. In the left sidebar, click on "Men" category to expand it.Men subcategories (Tshirts, Jeans) are visible.
4Click on "Tshirts" under Men category.Page shows "Men - Tshirts Products" heading with T-shirt products listed.
5In the Brands section on the left sidebar, click on "Polo".Page shows "Brand - Polo Products" heading. Product listing is filtered to Polo brand.
6Note the names of the first three products displayed.At least 3 products are visible in the listing.
7Click "Add to cart" on the first product. Click "Continue Shopping" in the modal.Modal shows "Added!" message. Modal closes after clicking Continue Shopping.
8Click "Add to cart" on the second product. Click "Continue Shopping" in the modal.Modal shows "Added!" message. Modal closes.
9Click "Add to cart" on the third product. Click "View Cart" in the modal.Cart page opens.
10Verify the cart contains exactly 3 items.3 product rows are displayed in the cart table.
11Verify each product name matches the names noted in Step 6.All 3 product names match.
12Verify the quantity for each product is 1.Quantity column shows "1" for each product.
13Verify the price is displayed for each product.Each product has a non-empty price value (e.g., Rs. 500).
